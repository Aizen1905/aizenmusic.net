隐私政策 Privacy Policy

适用于 Aizen Drive Backup · 生效日期 2026-10-16 · Effective 16 October 2026

1. 这是什么 / What it is

Aizen Drive Backup 是艾箴音乐自用的备份工具，在工作室自己的电脑上运行，把工作室自己的文稿与音乐成品单向备份到工作室自己的 Google Drive。它不向公众提供服务。

Aizen Drive Backup is a private tool used by Aizen Music. It runs on the studio's own computer and makes a one-way backup of the studio's own documents and finished music to the studio's own Google Drive. It is not offered to the public.

2. 访问哪些 Google 数据 / Google data accessed

本工具只申请 Google Drive 的 drive.file 权限，只能看到并管理它自己创建的备份文件和文件夹，看不到 Google Drive 中的其他任何文件，也不访问 Gmail、通讯录、日历等其他 Google 数据。

The tool requests only the Google Drive drive.file scope. It can see and manage only the backup files and folders it creates itself. It cannot see any other file in Google Drive and does not access Gmail, Contacts, Calendar or any other Google data.

3. 如何使用这些数据 / How the data is used

备份文件只用于工作室自己的存档与恢复。本工具不分析、不出售、不出租、不与任何第三方共享这些数据，也不用于广告或训练任何模型。

Backup files are used only for the studio's own archiving and recovery. The data is not analysed, sold, rented or shared with any third party, and is not used for advertising or for training any model.

4. 存储与保存 / Storage and retention

备份文件保存在工作室自己的 Google Drive 中，由工作室自行管理和删除。本工具不在其他任何服务器上保存数据。授权凭证只保存在工作室自己的电脑上。

Backup files are stored in the studio's own Google Drive and are managed and deleted by the studio. The tool keeps no data on any other server. Authorisation credentials are kept only on the studio's own computer.

5. 撤销授权 / Revoking access

可随时在 Google 账号的“第三方应用和服务”页面撤销本工具的访问权限：myaccount.google.com/permissions。

Access can be revoked at any time from the Google Account “Third-party apps & services” page: myaccount.google.com/permissions.

6. Google API 数据使用 / Google API data use

本工具对通过 Google API 获得的信息的使用和传输，遵守 Google API 服务用户数据政策，包括其中的有限使用要求。

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. 变更 / Changes

本政策如有变更，将在本页更新并注明生效日期。

Any change to this policy will be posted on this page with a new effective date.
